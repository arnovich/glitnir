# Glitnir 0.1.12 release notes

Changes since 0.1.11. This candidate remains a draft until its exact assets pass
verification and fresh-install checks.

## Notebook, Source and Explore

- Prominent Notebook, Source and Explore modes give each view its own layout.
  Notebook-only sidebars stay out of Source and Explore.
- Notebook contents nests theorem, lemma, corollary, definition and setup entries
  under their sections, with kind labels and colours independent of proof status.
  Section chevrons fold the contents separately from notebook content. The sidebar
  starts wider and supports dragging, keyboard resizing and width reset, with
  per-notebook layout preferences and selected-entry reveal.
- Source has a clearer editor surface, syntax styling, sticky line-number gutter
  and a Hide comments option that preserves literals and original line numbers.
  Line numbers visibly link back to Notebook. Static exports retain full source.
- Inspect proof steps is now an action on each claim, scoped to that declaration,
  with compatibility guards and a return to its reading position.

## Exploring larger proofs

- Read explains a selected argument, Route map shows a curated reading route,
  and Statement graph shows statements and their recorded links.
- The exploration sidebar owns route choices, search, current-step navigation and
  named visit history. Choosing a step or search result keeps the active view.
- Sources and details consolidates declaration references, source revision,
  statement status and copyable argument links. Redundant live supporting links,
  backlinks and pane controls are removed; static HTML retains its navigation.
- Atlas search, stable links, remembered reading positions, route comparison and
  coverage diagnostics support larger curated proofs, including the ETH example.
- The notebook authoring skill documents the updated exploration controls and
  authoring conventions. Curated explanation links do not certify Lean dependencies.

## Clearer status and controls

- Connection, proof availability and exceptional refresh activity share one header
  status group, with hover summaries and accessible details. The connection dot
  reports connection only; incompatible walkthroughs remain explicitly unchecked.
- Notebook controls sit below its title, keeping titles aligned across modes.
  Keyboard shortcuts live in Help. Imports retain their Edit in editor shortcut,
  and the filename tooltip exposes the local source path in live previews.

## Distribution and validation

Extension, backend and optional Forseti plugin are versioned 0.1.12. Python 3.12+
and Lean 4.35.0 remain required. The plugin retains its backend requirement
`>=0.1.10,<0.2`; the release does not change the supported checking toolchain.
The VSIX remains universal and thin.

The candidate manifest records the exact source, tag, original build and package
bindings. Verify original assets against SHA256SUMS and GitHub asset digests, then
complete fresh macOS/Linux installation checks before publishing. These notes
are not a validation receipt. Publish the verified draft without rebuilding or
changing its immutable tag or assets.
