# Glitnir 0.1.15 release notes

- Explore shows recorded tactic derivations and recognizes supported Forseti
  sequential composition and circuit substitution proofs.
- The top bar identifies active Lean work, including the names of diagrams
  being rendered. Open **Lean jobs** to see and stop running or waiting work
  across Glitnir previews in the same VS Code window.
- Glitnir menus pass modified keyboard shortcuts through to VS Code.
- Consecutive Lean `#print` commands in a source block are collapsed in
  Notebook view, with one edit button for the whole group.

The thin VSIX ships alongside matching backend and Forseti provider wheels.
