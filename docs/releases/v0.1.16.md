# Glitnir 0.1.16

Adds an optional notebook handoff provider API and the separately installed
`glitnir-taskvalet` package. **Send Notebook…** reviews the saved source and
research objective before creating an unqueued Taskvalet request. The owner
prepares assignments and launches any swarm on the board; the IDE does not launch
campaigns or treat a request as checked proof.

Handoff credentials are separate from compute credentials. Saved envelopes have
explicit recovery, retain their original source and destination, and cannot be
overwritten by another editor window. Definitive refusals may be retired for a
fresh preview; uncertain submissions retain their exact request ID.

The Taskvalet plugin is installed from a wheel through **Install Extension
Package…**. It is not part of the bundled Forseti release download. Publication
and installed release validation remain separate from this implementation.
