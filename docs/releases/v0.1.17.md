# Glitnir 0.1.17

Read notebooks at overview, explanation or full-detail depth, with independent
section expansion and per-notebook reading state within the preview session. The authoring skill now guides
layered arguments and readable LaTeX statements beside their Lean declarations.

Proof walkthroughs gain stronger provenance validation, named binder forwarding
and preservation of section type variables. Shared HTML notebooks use a light
presentation, and opening a notebook avoids starting the Lean source editor.
Lean compute workers bound thread usage per slot while preserving private caches.

The optional, separately installed `glitnir-taskvalet` provider adds reviewed
notebook handoffs, request status and source-bound results. Scoped swarm launch,
recovery and stop controls require configured access and readiness gates. The
installed end-to-end launch rehearsal remains outstanding; this release does not
establish a generally available hosted swarm service. Managed remote worker
lifecycle rehearsals and the planned public research workspace remain separate.
The Taskvalet provider is not included in these release assets.

The backend requires Python 3.12+. Checking and other Lean operations require
Lean 4.35.0. Install the VSIX with its matching backend wheel and, optionally,
the matching Forseti provider wheel. Verify the
published SHA256SUMS before installing assets.
