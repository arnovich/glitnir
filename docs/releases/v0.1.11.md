# Glitnir 0.1.11 release notes

These notes describe the changes since 0.1.10. The release candidate remains a
draft until its exact assets are verified and publication is approved.

## Reading and navigation

- Markdown HTTPS/mailto links, emphasis and mathematics in headings render in
  the shared preview. Inline code is preserved in link labels.
- Import headers collapse into one exact-source block. Empty prose no longer
  creates empty edit rows, and prose source controls align with their content.
- Embedded images open in a full-width viewer with keyboard activation and
  focus restoration. Routine explanations move behind accessible question-mark
  help icons.
- Recorded proof graphs and walkthrough statement maps show dependencies with
  readable node sizes, explicit details/document navigation, navigable
  relationships and stable scroll/focus through refreshes. Details retain every
  recorded use even when implied arrows are hidden in the map. Results whose
  environments were not compared are explicitly qualified.
- Curated proof atlases add reading routes and map exploration for large
  arguments, including shared steps, stable links and bounded navigation.
- Static HTML exports include exact Lean source and working links between
  document/source views and available sibling exports.

## Checking and evidence

- Notebook claim display preserves Lean section binders and can show bounded,
  display-only expansions of named propositions.
- Walkthroughs pinned to incompatible Lean versions remain unchecked, with
  compatibility explained in the preview and export.
- The optional Forseti plugin pins Forseti Lean 0.6.0 and adds closed hedging
  goals, exact binomial pricing/hedge calculations, checked decision blocks and
  sampled profit/loss evidence. Simulation remains evidence, never proof.
- Taskvalet research cards show bounded history. The repository also includes
  the Task031 two-round Lean evaluation evidence and workflow maintenance.

## Distribution and validation

The extension, backend and optional Forseti plugin are versioned 0.1.11. The
plugin retains its backend requirement `>=0.1.10,<0.2`; no new compatibility
floor is needed for this version bump. Python 3.12+ and Lean 4.35.0 remain the
runtime prerequisites. The VSIX stays universal and thin.

Candidate source, tag, original build and asset hashes are recorded in
`glitnir-candidate.json` and `SHA256SUMS`. Review the candidate's actual CI and
fresh-install evidence before publication. These notes are not a validation
receipt, and the draft release and Marketplace publication require separate
approval.
