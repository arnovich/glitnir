# Contributions

Glitnir is maintained by invited collaborators. We do not accept unsolicited
pull requests; GitHub pull request creation is restricted to collaborators.

The MIT licence permits you to use, modify and redistribute Glitnir, including
maintaining your own fork. It does not require the maintainers to accept changes
or provide support.

For installation and troubleshooting, start with the [README](README.md) and
[environment setup guide](extension/media/setup.md). Building and testing Glitnir
is described in [DEVELOPMENT.md](DEVELOPMENT.md). When reporting a problem through
[GitHub Issues](https://github.com/arnovich/glitnir/issues), include the Glitnir version and a minimal example.
Remove credentials, private notebook content and sensitive paths from logs.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening
a public issue. Support is best effort; no response-time guarantee is offered.
